## Опис проєкту

Цей репозиторій містить інтерактивний приклад виконання завдань третього рівня модульної контрольної роботи з теми **«Теорія ймовірностей та математична статистика»**.

У програмі реалізовано завдання 17–20. Для кожного завдання подано умову, використані формули, розрахунки та відповідь. Для завдання 20 додатково побудовано полігон відносних частот і графік емпіричної функції розподілу.

---

## Що реалізовано

У проєкті показано:

- обчислення математичного сподівання;
- обчислення дисперсії;
- обчислення середнього квадратичного відхилення;
- розрахунок ймовірностей для нормального розподілу;
- побудову довірчого інтервалу для середнього квадратичного відхилення;
- побудову варіаційного ряду;
- побудову статистичного розподілу вибірки;
- побудову полігону відносних частот;
- побудову емпіричної функції розподілу.
